# 🌟 Roshan - Knowledge Platform

## Enlightening Balochistan Through Understanding

### 📚 About the Project

**Roshan** (روشن) is an educational platform designed to transform the learning culture in Balochistan from memorization and cheating to genuine understanding and critical thinking.

### 🎯 Problem Statement

Students in Balochistan face significant challenges in developing a culture of genuine learning and academic integrity. Traditional education systems often fail to engage students, leading to a reliance on cheating rather than understanding.

### 💡 Solution

Roshan addresses this by:
- Providing engaging, interactive content across 5 disciplines
- Promoting understanding over memorization
- Integrating videos, book recommendations, and quizzes
- Creating a community of teachers and scholars
- Encouraging critical thinking and curiosity

### ✨ Features

- **5 Disciplines**: Islamic Studies, Astronomy, Psychology, Philosophy, Computer Science
- **Video Integration**: YouTube videos with curiosity prompts
- **Book Recommendations**: Curated reading for each discipline
- **Quiz System**: Interactive quizzes with explanations
- **User System**: Registration, Login, Profile, Progress Tracking
- **Admin Panel**: Full CRUD operations for all content
- **Image Upload**: For lessons, books, and profiles
- **Responsive Design**: Works on all devices

### 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Backend**: PHP 8.x
- **Database**: MySQL 8.x
- **Version Control**: Git & GitHub

### 🗄️ Database Schema

8 Tables:
1. `users` - User management (admin, teachers, students)
2. `categories` - 5 disciplines
3. `lessons` - Main educational content
4. `books` - Book recommendations
5. `media` - Images and infographics
6. `quiz_questions` - Interactive quizzes
7. `user_progress` - Learning tracking
8. `user_favorites` - Bookmarking system
9. `contacts` - Contact form messages
